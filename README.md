# Retail Sales & Growth Analysis Dashboard

## Overview
This project is an interactive Power BI dashboard developed to analyze retail sales performance and business growth.

## Tools Used
- Power BI
- Microsoft Excel
- DAX
- Data Modeling

## Dashboard Features
- Interactive Filters (Country, Year, Month, Quarter)
- KPI Cards
- Revenue Analysis
- Profit Analysis
- Product-wise Sales Analysis
- Waterfall Chart
- Donut Charts
- Line Chart

## Key Insights
- Analyzed revenue across categories and products.
- Tracked gross profit trends over multiple years.
- Compared sales performance using interactive filters.
